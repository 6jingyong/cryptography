# cryptography

一个面向**脏数据、变换域表示与组合隐写**的开放研究仓库。

当前第一阶段不实现完整通信协议，而是先验证一个更基础的问题：

> 给定一份天然包含噪声、缺失、舍入、漂移、重复和异常点的数据，仅通过可复现的分组与统计变换，能否得到“表面合理”的图表，同时在派生表示空间中形成稳定、可测量的离散结构？

## 研究核心

项目暂时围绕三个概念展开：

1. **Dirty-channel steganography**  
   不是把异常伪装成绝对正常，而是研究“人为结构”是否可以落入环境原本就存在的脏数据分布中。

2. **Transform-domain representation**  
   信息不必直接存在于原始数值中，可以研究它在区间几何均值、离散斜率、残差、分布统计等派生空间中的结构。

3. **Self-describing / multi-carrier structure**  
   同一数据集可以产生多个统计视图；多张图表也可以通过简单组合规则形成更高层结构。第一阶段只测量这种自由度，不实现完整编码协议。

## v0.1 假设

设原始数据：

\[
D=\{(x_i,y_i)\}_{i=1}^N
\]

将 \(x\) 划分为区间 \(B_j\)，对正值 \(y\) 计算区间几何均值：

\[
g_j=\exp\left(\frac{1}{n_j}\sum_{i\in B_j}\ln y_i\right)
\]

再定义离散斜率：

\[
s_j=\frac{g_{j+1}-g_j}{x_{j+1}-x_j}
\]

第一阶段关心的是：在保持数据分布、图形自然性和鲁棒性的条件下，\(s_j\) 以及同一区间内的分布统计是否仍存在可控的离散自由度。

## 第一阶段不做什么

- 不追求某个具体密码算法；
- 不追求最大隐藏容量；
- 不基于真实科研论文制造伪造数据；
- 不预设某一种特定的编码/解码协议。

先做可重复、可证伪的 benchmark。
