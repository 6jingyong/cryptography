# Synthetic dirty data v0

`synthetic_dirty_v0.csv` is generated by `src/generate_dirty_data.py`.

## Reproducibility

- seed: `20261031`
- base rows: `240`
- duplicate-like rows added: `6`
- total rows: `246`

Run:

```bash
python src/generate_dirty_data.py
```

## Columns

- `row_id`: row identifier
- `x`: ordered independent variable
- `y`: positive noisy measurement
- `source`: synthetic source label A/B
- `batch`: synthetic batch label; occasionally missing
- `quality_hint`: generator-side annotation (`ok` / `outlier_like`)
- `rounding`: number of decimal places used for the generated measurement
- `note`: occasional `manual_review` or `duplicate_like`

## Included dirtiness

The current dataset intentionally contains:

- heteroskedastic noise
- slow drift
- sparse outliers
- mixed rounding precision
- missing metadata
- duplicate-like records

The `quality_hint`, `rounding`, and `note` columns are included only to make v0 debugging easy. Later benchmark versions should provide a “blind” copy without generator-side hints for detection experiments.

## Important benchmark rule

The latent function used to generate `y` is **not** available to downstream grouping or optimization algorithms. It may be used only for benchmark evaluation.
